# PATINA releases

Signed release files for PATINA Foundry, the Linux installer for PATINA, a Rust music player
firmware for the iPod Video.

There are no releases yet. PATINA is experimental, and it has only been tested on one iPod Video
5.5G with 64 MB of RAM.

Foundry checks this repository's latest release and only accepts files signed with the key built
into it. Nothing installs by itself.
